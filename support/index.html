Know where your sound lives

Local files and Cloud recordings

Local

Audio in Blobular’s library on this iPhone. Recording or importing a file locally does not automatically upload it to Cloud.

Keep a separate copy of audio you want to preserve.

Cloud

Account-based recordings stored separately from your iPhone’s Local library. Saving to Cloud requires sign-in and an active subscription.

Cloud access is currently limited to approved testing; signing in does not automatically transfer your Local files.

A few answers

Common questions

How do I import audio?

Use the app’s audio import control and choose a file from Files. If the file is stored with a file provider such as iCloud Drive, make sure it has finished downloading before you import it. Select the imported sound in your Local library to play it.

How do I play audio fragments?

Choose a recording or imported file in your Local library, then start playback. Blobular uses short pieces of that sound as fragments. Experiment with the available fragment controls, and use the playback control to stop.

Where are my recordings stored?

Your Local library belongs to this iPhone. A Local recording is separate from an account’s Cloud recordings, and signing in does not turn Local files into a Cloud backup. Keep copies of important original audio outside the app.

How do I sign in?

Use your Modelglue account’s email and password for account-based services. A successful sign-in alone does not enable Cloud saving: an active subscription and enabled Cloud access are required. Contact support if you need help with an existing account.

How do I access Cloud recordings?

Cloud recordings are separate from the Local library and require an authorized account and an internet connection. Cloud access is in restricted testing. If you have not been given test access, use the Local recording, importing, and playback features.

What should I do if an upload or download fails?

Check your internet connection and account access, then try signing in again if your session has expired. For a failed upload, keep the Local original until the transfer is confirmed. For a failed download, check that your iPhone has free storage. If the problem continues, send support the error message and the steps that led to it.
